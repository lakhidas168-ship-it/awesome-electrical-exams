# GATE EE — official papers list

Source of truth: the GATE organising institute's own website for each year.
The organising institute rotates among the IITs/IISc; each year's site hosts
that year's question papers. Exact PDF URLs change yearly, so navigate from
the home page to the question-paper archive.

## Recent organiser sites (all opened 2026-09-28)

- GATE 2027 (IIT Madras): <https://gate2027.iitm.ac.in>
- GATE 2026 (IIT Guwahati): <https://gate2026.iitg.ac.in>
- GATE 2025 (IIT Roorkee): <https://gate2025.iitr.ac.in>

## How to find a paper

1. Open the organiser site for the year you want.
2. Look for "Question Papers" / "Old Question Papers" / "Download".
3. Pick the EE (Electrical Engineering) paper.
