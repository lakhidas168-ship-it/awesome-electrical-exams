# One-track plan (suggestion)

**(Suggestion — one possible order, not a rule. No cut-offs, timelines, or
scores are claimed here; check the official notification of each exam.)**

The EE syllabi of GATE, ESE, SSC JE, RRB JE, and State AE/JE overlap heavily,
so preparing them in one sequence avoids re-studying the same subjects:

1. **GATE EE core first** — Networks, Control Systems, Power Systems, Machines,
   Signals & Systems, Analog/Digital Electronics, EMFT, Measurements.
   Papers: the GATE organiser sites listed in [gate-ee-papers.md](gate-ee-papers.md).
2. **ESE Paper-I (General Studies)** — only after the technical core is stable.
   Papers: [ese-ee-papers.md](ese-ee-papers.md).
3. **ESE technical papers** — same core as GATE, with deeper derivations.
4. **SSC JE / RRB JE / State AE-JE** — EE core with objective speed practice;
   add state GK only from the respective state notification.

Adapt the order to whichever notification is actually out — the exam calendar,
not this file, decides what you study next.
